🌸 Kinta's Studio — Welcome to Notepad

A modern, aesthetic single-page developer notepad and knowledge base built with HTML, Tailwind CSS, and vanilla JavaScript. Features a Baby Pink & Soft Yellow palette, multi-language code snippets with logic breakdowns, screenshot paste & annotation, whiteboard drawing, checklists, video embeds, and local storage auto-save.

✨ Core Features & Functions

1. 🗂️ Topics & Section Management

Categorized Workspace: Organize notes by topics (e.g., Python Programming, Web Dev, DSA, Algorithms).

Topic Controls: Create new topics, rename existing ones, or delete entire sections using intuitive in-app modals.

Fast Note Creation: Add individual notes under any topic with automatic title, tag, and date tracking.

2. 📸 Screenshot Capture & Breakdown

Instant Clipboard Paste (Ctrl + V): Paste any screenshot copied from your snipping tool directly into your active note without saving a local file first.

File Upload: Upload images directly from your device.

Dedicated Breakdown Field: Every screenshot has an integrated analysis box beneath it to describe UI bugs, error logs, architecture flows, or test results.

Lightbox Zoom: Click to view screenshots in full resolution.

3. 💻 Multi-Language Code Blocks & Logic Notes

Syntax Highlighting: Supports Python, C, C++, JavaScript, Java, HTML/XML, CSS, SQL, and Bash powered by Prism.js.

Code Explanation Box: Dedicated notes section beneath every code editor to explain line-by-line execution logic, complexity ($O(n)$), and edge cases.

One-Click Copy: Fast copy button to quickly grab raw code snippets.

4. 🎨 Whiteboard, Drawing & Screenshot Markup

Drawing Tools: Pen, semi-transparent Highlighters, Eraser, stroke size control, and custom color picker.

Color Swatches: Quick-select color palette (Baby Pink, Deep Rose, Soft Yellow, Mint, Pastel Cyan).

Background Guides: Toggle between Blank Canvas, Dot Grid, and Lined Grid.

Annotate Screenshots: Load any image directly onto the drawing canvas to circle bugs, highlight code, and draw arrows over diagrams.

PNG Export: Download your drawings and diagram sketches with one click.

5. ✅ Interactive Checklists & Callouts

To-Do / Action Items: Add checklists with real-time strike-through completion status.

Insight Cards: Add styled Callout cards for Tips, Warnings, or Formulas & Rules.

Quick Markdown Actions: Format text with bold, italic, inline code, text highlights, and bullet lists.

6. 🎥 Multimedia & Documents

Video Embeds: Supports YouTube embed URLs and local video files (.mp4, .webm) with dedicated timestamp notes.

Document Attachments: Upload files (.pdf, .txt, .md, .json, .csv, .doc) with file size badges and an inline text previewer.

7. ⏱️ Auto Timestamps & Reading Analytics

Created & Updated Tracking: Records initial creation time and automatically updates the last modified timestamp down to the second.

Live Metrics: Real-time word counter and estimated reading time.

8. 💾 Storage & Data Portability

Auto-Save: Saves all edits to localStorage automatically with live saving indicators.

Full Workspace Backup: Export and import the entire notebook state as a JSON file.

Document Export: Export single notes directly to formatted Markdown (.md) or standalone styled HTML (.html).

Dark & Light Mode: Toggle between a pastel Baby Pink theme and a dark plum contrast theme.

🚀 Getting Started

No installation, build tools, or server setup required!

Clone or download this repository:

git clone https://github.com/your-username/kintas-studio.git


Open index.html in any modern web browser (Chrome, Edge, Firefox, Safari).

Start taking notes!
